# Candidate Contributions

These are intended contributions, not demonstrated novelty or effectiveness claims.

1. **A task-scoped authorization model:** a framework-neutral vocabulary connecting declared goals, resources, actions, constraints, approvals, and execution limits.
2. **An external deterministic enforcement architecture:** a reference-monitor design that keeps fundamental authorization independent of the protected agent and optional semantic models.
3. **An observable trajectory model:** canonical ordered events for testing whether stateful rules add value beyond individual action checks.
4. **Graduated containment semantics:** defined outcomes from allow through capability degradation, quarantine, and termination, with auditable state transitions.
5. **A threat and benchmark taxonomy:** registered agent threat scenarios linked to candidate experiments and measurable outcomes.
6. **A comparative evaluation protocol:** matched deterministic, LLM-only, and hybrid baselines measuring safety, utility, performance, economics, and reproducibility.
7. **A reproducible evidence chain:** traceability from research question and hypothesis through versioned experiment metadata to immutable results and bounded claims.

Novelty will be assessed only after the related-work review. Contribution strength will be revised in response to experimental evidence and limitations.
